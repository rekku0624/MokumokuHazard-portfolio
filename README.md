# もくもくハザード
### 〜 副流煙を避けたい人のための「喫煙スポット ハザードマップ」アプリ 〜

> DigiTaKaQ(北九州市主催)スマホアプリ開発コース 優秀賞受賞作品(じょぎ+1チーム)
> 3人チーム・開発期間2週間

※ソースコードはチームの非公開リポジトリで管理しているため、本ページでは作品概要と自身の担当を紹介しています。

## 背景と課題
北九州では路上喫煙に出くわすことが多く、「副流煙(もくもく)を避けたい」という声がありました。
しかし、どこに喫煙所があり、どこで路上喫煙が多いのかを事前に知る手段がありませんでした。

## 解決策
喫煙所や路上喫煙が多い地点をユーザー同士で共有し、地図上で「避けるべき場所」が一目で分かるようにしました。

## 一押しポイント:緊急喫煙者警報
危険度が高い場所に近づくと、**アラート音とバイブレーションで警報(緊急喫煙者警報)が鳴ります。**
スマホを見ていなくても、歩いているうちに副流煙スポットに気づき、避けることができます。

## 主な機能
| 画面 | 内容 |
|---|---|
| サインイン / サインアップ | アカウント登録とログイン |
| マップ画面 | 現在地と、喫煙所・路上喫煙スポットを地図上に表示 |
| アラート画面 | 危険度の高い場所に近づくと警報を表示し、音と振動で通知 |
| マーカー作成画面 | 喫煙スポットを見つけたユーザーが地図に登録・共有 |
| プロフィール画面 | 名前、設置したマーカー数、設置したマーカー一覧を表示 |

## 自分の担当

### 企画:アラート音とバイブレーションによる警報を提案
- **当初の仕様**:危険な場所に近づくと、アラート画面に切り替わるだけ
- **気づいた課題**:歩いている間はスマホを見ていないことが多く、画面が変わるだけでは警報に気づけない
- **提案**:画面の切り替えに加えて、アラート音とバイブレーションで知らせる
- **結果**:チーム内で採用され、本アプリの一押しポイント「緊急喫煙者警報」の中心になった

### 実装
- **ログイン画面**:UIデザインの検討と実装
- **アラート画面**
  - UIの実装
  - アラート音の再生機能
  - アラート音と連動したバイブレーション機能
  - 一定時間警報を鳴らした後、自動で元の画面に戻る画面遷移

- 初めてのチーム開発で進め方が分からなかったが、分からない点は先輩やメンターに相談しながら一つずつ解決した
